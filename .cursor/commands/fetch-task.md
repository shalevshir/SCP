# fetch-task

Fetch all tasks from Notion with status = ‘In Progress’. Rank them by their numeric ordering field (e.g., priority, sequence, or custom sort number). Choose the next task by selecting the one with the lowest active number.

After selecting the task, generate a complete implementation plan that includes:

objective and expected outcome

required context and dependencies

technical steps and subtasks

validations and edge cases

estimated complexity/time

Definition of Done for this task

If necessary, ask for missing information before proceeding.
